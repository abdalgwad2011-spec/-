# انصحني - Flutter

## التشغيل
flutter pub get
flutter run

## المصحف كامل
المصحف يتحمل سورة سورة من النت عبر api.alquran.cloud - يعمل في التطبيق الحقيقي بدون حظر.

## دخول الشيخ (سري)
اضغط على اللوجو 5 مرات -> كلمة السر 1234

## بناء APK
flutter build apk --release
الملف سيكون في build/app/outputs/flutter-apk/app-release.apk

## رفع على Google Play
flutter build appbundle --release
